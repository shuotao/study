  3. K3導入 AI 第一步：用團隊累積的知識當 context，產出仍需檢查

  5. K5好學生矩陣的四個象限：先有完整脈絡，才能產生重點
  6. K6第三象限追查與檢核往深處，第四象限用 tag 連結其他場次
  7. K7把任務拆成 phase：確定性的工作給工具，判斷給 AI，最後決定給人
